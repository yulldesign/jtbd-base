# 9. Prioritize features against jobs

## Idea

Starting from job statements, brainstorm the features that could deliver that specific value. When several jobs matter, give each roadmap interval (a sprint, a quarter) one job as its theme.

## Proposed steps (to validate in practice)

1. Take the outcomes with the highest opportunity scores.
2. For each one, brainstorm features and note which outcomes each feature would move.
3. Score the features on outcome coverage and effort.
4. Make one job the theme of the next interval.
